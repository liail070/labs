# Учебные лабораторные работы по Python

Репозиторий объединяет две учебные работы по программированию на Python:
разработку объектно-ориентированной модели социальной сети и создание
инструмента для проверки и поиска корректных римских чисел с
использованием регулярных выражений.

## Содержание репозитория

| Работа | Тема | Что реализовано | Документация |
|:---:|---|---|---|
| ЛР1 | ООП: модель социальной сети | Разработка классов и структуры предметной области, операции добавления, поиска, изменения и удаления данных, обработка ошибок, работа с JSON и XML, UML-диаграмма | [README лабораторной № 1](README_ЛР1.md) |
| ЛР2 | Регулярные выражения и unit-тестирование | роверка корректности римских чисел, поиск римских чисел в тексте, чтение текстовых файлов, получение данных из веб-страниц, автоматизированное тестирование | [README лабораторной № 2](README_ЛР2.md) |

## Как начать работу

1.  Откройте README нужной лабораторной работы по ссылкам в таблице
    выше.
2.  Ознакомьтесь с требованиями к версии Python и необходимыми
    зависимостями.
3.  Следуйте инструкциям по установке, запуску программы и выполнению
    тестов.
4.  В папках соответствующих лабораторных работ находятся исходный код,
    данные, диаграммы и другие материалы.
