Репозиторий объединяет две учебные работы по программированию на Python:
разработку объектно-ориентированной модели социальной сети и создание
инструмента для проверки и поиска корректных римских чисел с
использованием регулярных выражений.

## Как начать работу

1.  Откройте README нужной лабораторной работы по ссылкам в таблице
    выше.
2.  Ознакомьтесь с требованиями к версии Python и необходимыми
    зависимостями.
3.  Следуйте инструкциям по установке, запуску программы и выполнению
    тестов.
4.  В папках соответствующих лабораторных работ находятся исходный код,
    данные, диаграммы и другие материалы.
