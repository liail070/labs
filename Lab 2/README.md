# Лабораторная работа № 2
## «Регулярные выражения. Unit-тестирование»
**Вариант 20 — проверка и поиск синтаксически корректных чисел в римской системе счисления.**

## 1. Назначение проекта

Программа проверяет корректность записи отдельного римского числа и ищет римские числа в пользовательском тексте, локальном текстовом файле или на веб-странице, загружаемой по URL.

Поддерживается классическая каноническая запись целых чисел от **I (1) до MMMCMXCIX (3999)**. Регистр букв не учитывается.


- `requirements.txt` — внешняя зависимость `requests`.

## 3. Формализация предметной области

Для канонической записи чисел используются следующие правила:

| Разряд | Допустимые формы |
|---|---|
| Тысячи | `M{0,3}` |
| Сотни | `CM`, `CD`, `D?C{0,3}` |
| Десятки | `XC`, `XL`, `L?X{0,3}` |
| Единицы | `IX`, `IV`, `V?I{0,3}` |

Полное регулярное выражение:

```regex
^M{0,3}(?:CM|CD|D?C{0,3})(?:XC|XL|L?X{0,3})(?:IX|IV|V?I{0,3})$
```

Якоря `^` и `$` требуют совпадения со всей строкой. Поэтому, например, `XIV` проходит проверку, а `XIIII`, `IC`, `VX` и `MMMM` — нет. Допускается диапазон от 1 до 3999; пустая строка не является числом.

При поиске в тексте используются границы, не позволяющие считать частью результата фрагмент буквенного слова. Например, `CIVIL` не превращается в найденное `CIV`.

## 4. Установка и запуск

Рекомендуется Python 3.10 или новее.

### Windows (PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Проверка одного числа

```powershell
python main.py --check MCMXCIV
python main.py --check IIII
```

### Поиск в тексте

```powershell
python main.py --text "Глава IV, том XII"
```

### Поиск в файле

```powershell
python main.py --file data/example.txt
```

### Поиск на веб-странице

```powershell
python main.py --url https://example.com
```

Для загрузки веб-страниц требуется подключение к интернету. Программа проверяет HTTP-ошибки и использует ограничение времени ожидания запроса.

### Интерактивный режим

```powershell
python main.py
```

Без аргументов запускается меню. В нём можно проверить число, выполнить поиск в тексте, файле или на веб-странице.

## 5. Unit-тестирование

Тесты написаны с помощью стандартного модуля `unittest`. Запуск из корневой папки проекта:

```powershell
python -m unittest discover -s tests -v
```

Проверяются:
- базовые и составные корректные числа;
- строчные и смешанные буквы, пробелы по краям;
- запрещённые повторы и неправильные вычитательные сочетания;
- пустые строки, посторонние символы и значения неверного типа;
- поиск нескольких чисел, границы слов, пунктуация и пустой текст;
- чтение файла, отсутствие файла;
- успешная загрузка URL, некорректный URL и HTTP-ошибка.
